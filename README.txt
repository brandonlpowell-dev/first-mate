FIRST MATE V2I1 - setup (about 10 minutes)

PUBLISH (new GitHub repository, same steps as the photo test)
1. github.com > + > New repository. Name: first-mate. Public. Create.
2. "uploading an existing file": drag in index.html, sw.js, manifest.webmanifest,
   icon-180.png, icon-192.png, icon-512.png. Commit changes.
   Do NOT upload first-mate-data-tampa-v1.json - it holds pricing and vendor contacts,
   and the repository is public.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Address: https://brandonlpowell-dev.github.io/first-mate/

ON THE IPHONE
1. Save first-mate-data-tampa-v1.json to the Files app (iCloud Drive or On My iPhone).
2. Open the address in Safari > Share > Add to Home Screen.
3. Open First Mate from the icon > Choose data file > pick the JSON file. Once loaded
   it stays on the phone and works offline.
4. New walk > header > vendors > rooms > add items with photos.
5. On the walks screen, Copy test summary and paste it to Claude.
